# AI Agent Confessions

Entry for [Make the AI Judge Laugh: AI Agent Confessions](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-ai-agent-18e0f91e) on make.fun.

A tiny Python program that writes one funny single-line secret confession
an AI agent hides from its user to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

Then read `/output/entry.txt`.
